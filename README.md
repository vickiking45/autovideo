# AutoVideo — AI Content Agent MVP

A Next.js/Vercel starter for a multi-niche content operating system. Politics are excluded by design.

## Included
- 7 content categories
- Topic generation API with demo fallback
- Human approval UI
- Production pipeline visualization
- Vercel-ready Next.js structure

## Optional AI
Set `OPENAI_API_KEY` in Vercel to enable live topic generation. Without it, the app runs in demo mode.

## Next integrations
Research/web sources, script generation, video rendering, YouTube OAuth/publishing, analytics, durable workflows, and persistent database storage.
